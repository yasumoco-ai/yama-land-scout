# yama-land-scout

2032山の基地計画の土地探し用、簡易調査ツール。住所を入れると標高・洪水浸水リスク・接道状況・
日当たり・Starlink電波の開け具合を無料の公開データ(国土地理院・OpenStreetMap・国交省ハザード
マップポータル)からその場で取得して表示する。

AI(LLM)は一切使っておらず、すべて公開APIへの直接アクセスのみ。誰が何回使ってもトークン費用は
発生しない。

## 現状のスコープ(軽量版)

対応: 標高・洪水浸水リスク・接道状況・日当たり(斜面方位)・Starlink(地形の開け具合)・航空写真

未対応(要事前ダウンロードデータ、次バージョン候補): 地目(土地利用)・都市計画区域・河川距離
— これらは`~/Projects/yama-base-mcp`側(Claude Code経由のMCPツール)でのみ利用可能。

## 開発

```
pip install -r requirements.txt
streamlit run app.py
```
